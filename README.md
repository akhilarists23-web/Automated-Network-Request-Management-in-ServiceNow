# Automated Network Request Management in ServiceNow

This project presents an Automated Network Request Management solution developed using ServiceNow.

## Project Documentation

The complete project documentation is divided into five phases:

### Phase 1 – Project Overview
Project introduction, objectives, requirements, and initial planning.

### Phase 2 – Backend Development & Configurations
Creation and configuration of the custom database table and required fields.

### Phase 3 – User Interface & Workflow
Configuration of the Service Catalog, variables, UI policies, workflow, and request processing.

### Phase 4 – Data Migration, Testing & Security
Automation, access control, QA testing, and data integrity validation.

### Phase 5 – Documentation & Presentation
Final documentation, technical blueprint, setup manual, project demonstration, and presentation.

## Technologies Used

- ServiceNow
- Service Catalog
- Custom Tables
- Catalog Variables
- UI Policies
- Flow Designer
- Approval Workflow
- Email Notifications
